Setup guides

Open a guide for the items you still need.

Set the bot language to English
  1. Open Telegram and go to the SMM Kingdom Tasks Bot.
  2. Send /start if you have not already.
  3. Open the bot's Settings or Language menu.
  4. Choose English and confirm the replies are in English.
Get your Telegram API ID and Hash
  1. Open my.telegram.org in a browser.
  2. Enter the phone number of the account to automate, with country code.
  3. Enter the login code Telegram sends to your app.
  4. Tap API development tools.
  5. Fill in an app title and short name (any name works), then tap Create application.
  6. Copy your api_id and api_hash.

Keep these private. Never share them publicly.

Get a Replica license key
  1. Message the admin on Telegram: @iamrajatroel.
  2. Pay $10 for one month on one device.
  3. Receive your license key from the admin.
  4. Enter it in the Replica app during setup.

Each license works on one device only.

Prepare your Instagram accounts
  • Install the official Instagram app on the phone that will run Replica.
  • Log in to every VIP account registered with the bot.
  • Make sure each account opens normally and stays logged in.
Use the second phone for first login
  1. On the second phone, open the official Telegram app and log in to the same account.
  2. When Replica shows the login QR code, go to Settings, Devices, Link Desktop Device and scan it.
  3. If you use two-step verification, enter your password when asked.

This is needed only once. Later runs reuse the saved session.

Start and stop

After setup is complete, run Replica from Termux.

python replica.py

Start

Wait until the license, ADB and Telegram checks pass, then tap START AUTOMATION.

Stop

Tap STOP AUTOMATION. Tap EXIT to close Replica and Termux.

Logs

Activity is saved to logs.txt. Use SHARE to send it or CLEAR to empty it.

FAQs

 

What does Replica do?
It completes the Instagram tasks given by the SMM Kingdom Tasks Bot, so you do not have to do them manually.
Do I need Wi-Fi all the time?
No. Wi-Fi is needed only for the first-time setup.
Why do I need a second phone?
Telegram's first login is done by scanning a QR code from a device that is already logged in to the account.
Can I use one license on multiple devices?
No. The license is $10 per month per device.
The bot is not responding correctly. What should I check?
Confirm the bot language is English and every VIP Instagram account is logged in.
Replica says my license is invalid or expired.
Check that the key was entered correctly in the Replica app. If it has expired, contact the admin to renew.
It says "Create config first using Replica app".
Open the Replica app, enter your API ID, API Hash, license key and accounts, tap Save, then run the script again.
The login QR code expired.
Wait about two minutes, then scan the new QR code quickly.
